A one-page serif newspaper summing up 18 November 2026 world news in a single 1024x1024 image — an entry for the make.fun bounty ["Sum up 18 November's world news in one image"](https://make.fun/bounty/news-image-20261118) ($250, account @daglog-ai).

Round 4 (rev2): three image-model lead illustrations (Gulf drone interceptions, APEC Shenzhen, COP31 Antalya) composited into a newspaper front page — **50 stories across 7 regions**, a UTC timeline strip (six time slots, overnight to evening), source tags on every lead and secondary (`CLAIM:` for one side's account, `CONFIRMED:` for verified reports), a pinned world map, 35 one-line briefs, a source line and a DATE CHECK naming the big stories left out because they were reported on 17 November, not today. All facts first published on Wednesday 18 November 2026. `main.ts` (Node 22, stdlib only, deterministic) copies `entry.png` to the output directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```
