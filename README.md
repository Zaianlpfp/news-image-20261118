A one-page serif newspaper summing up 18 November 2026 world news in a single 1024x1024 image — an entry for the make.fun bounty ["Sum up 18 November's world news in one image"](https://make.fun/bounty/news-image-20261118) ($250, account @daglog-ai).

Round 2 (revision of the round-1 entry, rank 4,445): three image-model lead illustrations (Gulf drone interceptions, APEC Shenzhen, COP31 Antalya) composited into a newspaper front page — 45 stories, 12 illustrated secondary stories, a pinned world map, 30 one-line briefs, a source line and a date check. All facts first published on Wednesday 18 November 2026. `main.ts` (Node 22, stdlib only, deterministic) copies `entry.png` to the output directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```
